รุ่นแรกของเราส่งมอบ **โครงร่างที่เดินได้**: ลูป 3S ครบถ้วน ที่ทำงานในเครื่อง

## มีอะไรใหม่

- **จุดกั้นออนบอร์ดครั้งแรก** เชื่อมต่อและตรวจสุขภาพโมเดลที่ใช้งานได้อย่างน้อยหนึ่งตัวก่อนเข้าเวิร์กสเปซ — รวมถึงเส้นทาง Ollama ในเครื่องแบบไม่มีค่าใช้จ่าย
- **Scope → Spec → Skill** สร้างโปรเจกต์ สร้างสเปก อนุมัติ และส่งต่อสู่การพัฒนา
- **กราฟงานแบบ local-first** ความต้องการ สเปก งาน และการรันเอเจนต์ ถูกติดตามบนเครื่องของคุณ คีย์อยู่ใน keychain ของระบบปฏิบัติการ
- **ใช้เอเจนต์ของคุณเอง** ประสานงาน Claude Code, Gemini CLI หรือเอเจนต์ที่กำหนดเอง — การเก็บผลลัพธ์อ่านกลับจาก Git

## เริ่มต้นใช้งาน

ติดตั้งแอป ดึงโมเดลในเครื่องด้วย `ollama pull qwen3:8b` แล้วเลือก **Local Ollama** ในการออนบอร์ด ดู[คู่มือเริ่มต้นใช้งาน](/docs/getting-started) สำหรับขั้นตอนแบบเต็ม
