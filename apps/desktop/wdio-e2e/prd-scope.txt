Make Story Time 2.0 is a web app that lets users create personalized illustrated/audio stories for kids and adults. Users pick a genre/template, build a main character (name, age, traits, favorite things, special abilities), choose a target audience (young 3-8, middle-grade 9-12, teen, adult), set a time/place, theme/conflict/moral, and optional special requests. The app generates a custom story via an AI text-generation API, converts it to narrated audio via a text-to-speech API, and presents it in an immersive mobile-first book reader with page-turn animations and a persistent audio player. Users pay $15 per story via Stripe Checkout before generation starts, get an email confirmation, and can download the finished story as PDF and MP3. A user dashboard lists all of a user's stories with quick read/download access and creation metadata.

Core entities: Users, Stories (title, content, audio_path, target_audience, status: pending/processing/generated/completed/failed), Characters (per-story, with traits/favorites/special abilities), StoryTemplates (genre + prompt template), StorySettings (time period, location, theme, conflict, moral, special requests), Payments (Stripe payment id + status).

Non-functional requirements: mobile-first responsive design throughout; secure payment flow with webhook-driven status updates; proper auth/authorization; input validation and CSRF protection; efficient database queries and asset caching; regular backups of story data. Future (not in this scope): print-on-demand, gift/sharing, offline reading, subscriptions, multiple narration voices, interactive story elements.
