# Rename allowlist (PromptConnext → PromptWorkspace)

PromptConnext is the company; PromptWorkspace is the product. On 2026-10-03 every product-name token in this repo was rewritten by one scripted, fixture-tested token map (`scripts/rename/rename.py`, patterns in `scripts/rename/patterns.py`). The same patterns back the CI gate, `scripts/rename/check.py` (job `rename-gate` in `ci.yml`, or locally `scripts/rename-check.sh`), which fails on any surviving left-hand side of the map: `PROMPTCONNEXT_`, `PZ_`, `pz_`, `_pz_`, `pz-cloud`, `pz-documents`, `pz-preview`, `@promptconnext/`, `promptconnext://`, `PromptZone`, `promptzone` and `promptconnext` in any casing.

The pre-rename tree is tag `pre-promptworkspace-rename`.

## Spans that keep the old word

`scripts/rename-allowlist-patterns.txt` holds one regex per line. Each one matches a token span, never a whole line: the checker blanks the span and searches the rest of the line again, so a line holding both `promptconnext.com` and a stray `pz_` still fails. Every span is one where "PromptConnext" names the company or an identifier fixed outside this repo:

- **The GitHub org.** `github.com/PromptConnext/`, `git@github.com:PromptConnext/`, and the bare `PromptConnext/<repo>` slug before `PromptWorkspace`, `promptconnext-corp-web` or `promptconnext-projects`.
- **Sibling repo names.** `promptconnext-corp-web` and `promptconnext-projects` (the umbrella).
- **The Marketplace publisher.** `"publisher": "promptconnext"`, which makes the extension ID `promptconnext.promptworkspace`; that ID is allowlisted too.
- **The Tauri identifier.** `com.promptconnext.promptworkspace` (reverse-DNS of the company domain).
- **Company domains.** `promptconnext.com` (and its subdomains, e.g. `api.workspace.promptconnext.com`), `promptconnext.truthledgers.com`, `no-reply@promptconnext.com`. Each has a right boundary, so `promptconnext.commitScanLimit` is *not* mistaken for the domain.
- **Company and copyright spans.** `© <year> PromptConnext`, `Copyright (c) <year> PromptConnext`, `PromptConnext Co.`, `<verb> by PromptConnext` for the company verbs only (`hosted`, `managed`, `minted`, `supplied`, `built`, `made`, `operated`, and never when followed by `Cloud`, `Workspace`, `Desktop`, `MCP` or `extension`, so "seeded by PromptConnext Cloud" is renamed), `PromptConnext company`, `PromptConnext is the company`, and the LICENSE's `permission from PromptConnext`.
- **The pre-baseline table prefix.** `PRE_BASELINE_TABLE_PREFIX = "pz_"` in `apps/cloud/scripts/migrate.py`, the one constant the runner uses to recognise (and refuse) a database still on the old table names.
- **Links to dated historical docs.** `promptzone-{design-system-plan,diagrams,platform-architecture,product-roadmap}.md` and `promptzone-graph.png` keep their file names, so references to them do too.

## Whole files left as written

Dated historical documents stay as written (decision D3, following umbrella ADR 0002's precedent). The checker and the map skip these path prefixes: `docs/plans/`, `docs/decisions/`, `docs/reports/`, `docs/superpowers/`, `docs/overnight/`, `docs/research/`, `docs/product-vision-*`, `docs/promptzone-*`. They also skip `pnpm-lock.yaml` (regenerated by `pnpm install`, never edited) and the rename tooling itself. Binary files are skipped.

## Adding an entry

Add one only for a span where the old word is the company or an external identifier, and keep it a span with a right boundary. If a new product-name token turns up, rename it instead.
