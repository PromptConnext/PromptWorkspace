02/The thing worth defending

Nobody else can say which tasks are in this build

Strip the workflow branding and one capability is genuinely differentiated: an unbroken line from a business requirement to a running, deployed application.

"A project-management tool knows the task closed. A deployment dashboard knows the build shipped. This is the only system that knows they're the same event."

03/Decided yesterday

Three questions that were blocking everything else

Sixteen implementation plans came out of the vision review. Three decisions were the gate in front of most of them. All three are now made and recorded in the ADRs, not just in a conversation.

Decided

What happens to the desktop

Retire both shells

The VS Code extension is already larger and more current than either the Tauri app or the Theia shell it would replace. Both have sat frozen for a month with no owner. The MCP server — the portable channel for every other editor — moves from a long-term bet to a release prerequisite.

ADR 0019 · ADR 0020 · plan 0011
Decided

What's free

Metered free planning

Scope, Spec and the task graph are free for any workspace, bounded by a lowered token ceiling. Paid starts at repository provisioning, deployment and the live preview — where the platform's own costs actually sit.

new ADR 0027 · plan 0022
Decided

Direct database writes

Revoke client access

Row-level security in Postgres was more permissive than the API. The web app's only Supabase dependency never touches the graph tables anyway, so revoking costs nothing real and closes a live bypass.

06/Where this goes

Governed delivery, not another AI coding tool

It ships no model, no agent runtime, and — after the pivot — no editor. What it owns is the record of how a requirement became running software, who approved each step, and which build a task ended up in. That's a governance and auditability product wearing a planning-tool interface.

Bet one

Compliance as evidence, not a prompt prefix

Policy text today just steers a generation prompt. The next step is an export an auditor accepts — obligations, coverage, immutability.

Bet two

Freeze the evidence graph

Stable task identity across regenerations, and build attribution computed once instead of recomputed on every delivery.

Bet three

One server, every editor

The MCP server ADR 0019 specified and nobody built — the only channel left once the shells are gone.

Bet four

Templates as the growth surface

A new deployment target is a directory and a registry entry — the cheapest way to widen what this platform can ship.

The market signal is already in the code — it's just never been said out loud.

07/Scope discipline

What we're stopping

  • Both desktop shells — the Theia planner interface that milestone three would have built.
  • The local Spec Kit stage runner — two implementations of one workflow, and only the cloud one runs.
  • ClickUp — registered but its credential path only ever resolves Jira. Every call fails silently.
  • Scanned-document OCR — the provider intentionally raises rather than pretending to work. Say so in the UI.
  • Per-stage model routing — the selector is a pass-through and the ADR already dropped the idea.
